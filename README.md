## Preparar ambiente
Na página inicial do repositório, clique no botão verde "CODE" e copie o URL que aparece na janela.

Abra o seu VS Code e navegue até a pasta aonde ficará seu projeto. Abra o terminal Git Bash e copie `git clone` seguido do Link do repositório. Ao confirmar, o repositório será baixado no seu computador.

## Ambiente virtual
Você precisa criar um ambiente virtual antes de começar a trabalhar no projeto. Lembre-se que NÃO se pode fazer o upload da sua venv ao repositório.
Com o Python instalado no seu computador, vá até a raiz do seu projeto e execute `python -m venv venv` no Git Bash.
Se a pasta venv aparecer na raiz do projeto, você já pode executar `source venv/Scripts/activate` para ativar a máquina virtual.
