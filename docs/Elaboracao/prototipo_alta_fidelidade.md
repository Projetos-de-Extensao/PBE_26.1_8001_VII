## Protótipo de Alta Fidelidade

O protótipo de alta fidelidade representa a interface final do sistema de gestão de estágio, com navegação, cores e componentes próximos do produto real.

### Ferramenta Utilizada

O protótipo foi desenvolvido no **Figma**, contemplando as principais telas do sistema.

### Telas Prototipadas

| Tela | Descrição |
| --- | --- |
| Login / Cadastro | Autenticação de usuário via e-mail e senha |
| Feed de Postagens | Listagem das postagens dos perfis seguidos |
| Perfil | Visualização e edição de dados do perfil |
| Publicar Postagem | Formulário de criação de nova postagem |
| Mensagens | Conversa privada entre dois perfis |
| Notificações | Interações recebidas (curtidas, comentários, compartilhamentos) |
